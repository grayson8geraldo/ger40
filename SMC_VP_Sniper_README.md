# SMC + Volume Profile Sniper — TradingView Indicator

Индикатор объединяет автоматизированную структуру рынка (Lewis Kelly),
ICT/SMC сетапы (Faiz), Volume Profile ночной сессии NY и даёт точки входа
по **Failed Auction** и **Breakout** с автоматическим расчётом SL/TP1/TP2.

---

## 1. Как установить

1. Откройте TradingView → **Pine Editor**.
2. Скопируйте код из `SMC_VP_Sniper.pine` и вставьте в редактор.
3. Нажмите **Add to chart**.
4. Рекомендуемый рабочий таймфрейм графика: **5-минутный**
   (на нём индикатор считает LTF-сигналы 1M через `request.security`).

## 2. Логика работы

| Этап | Что делает индикатор | Инструмент |
|------|---------------------|------------|
| 1 | Считает EMA50 на HTF 4H — глобальное направление | `htfUp / htfDn` |
| 2 | Находит свинги на MTF 15M, фиксирует **BOS / CHoCH** (пробой **телом**) | Фракталы, `trendBias` |
| 3 | Строит Volume Profile ночной сессии **18:00–08:55 NY** — VAH/VAL/POC | Fixed Range |
| 4 | Детектит **Fair Value Gap** на LTF 1M | 3-свечной гэп |
| 5 | Триггерит сетап только если свечка закрылась обратно в Value Area (Failed Auction) ИЛИ цена закрепилась за VA 3 свечи подряд + BOS/CHoCH + FVG в сторону пробоя | Комбинированный фильтр |
| 6 | Разрешает сигнал только в **Kill Zones** (London 02:00–05:00 NY, NY 08:30–11:00 NY) | Сессионный фильтр |
| 7 | Считает **SL = 1.2 × ATR(14)**, **TP1 = 1.5 RR**, **TP2 = 3 RR или противоположная граница VA** | ATR + Value Area |

## 3. Правила торговли (чеклист трейдера)

**LONG:**
- HTF 4H цена выше EMA50 ✔
- MTF 15M: последнее событие CHoCH↑ или BOS↑ → `bias = BULL`
- Цена ушла ниже VAL и вернулась телом внутрь VA (Failed Auction) **или**
  пробила VAH и закрепилась (Breakout)
- На 1M образовался **бычий FVG** в направлении сделки
- Время входа — London KZ или NY KZ

**SHORT:** зеркально.

## 4. Риск-менеджмент (для «разгона депозита»)

- **Риск на сделку: 1–2 % от депозита.** Никогда не повышайте — один убыток
  при 10 % риска съедает две выигрышные сделки.
- Выход частями: **50 % на TP1**, стоп в безубыток, остаток — на TP2.
- Максимум **3 сделки в день**. После 2 SL подряд — стоп на день.
- Не торгуйте в первые 5 минут после выхода новостей высокой важности.

## 5. Мои улучшения (сверх вашего ТЗ)

1. **HTF-фильтр через EMA50 на 4H.** Отсекает сделки против глобального
   тренда — именно это повышает винрейт до 55–60 %.
2. **Kill Zones (London / NY).** Статистика ICT подтверждает, что 70 %
   движений дня случаются в этих окнах; вне их — ретест и шум.
3. **Liquidity Sweep (`sweepHigh` / `sweepLow`).** Дополнительная переменная
   фиксирует съём стопов как условие для более агрессивной входной логики
   (можно включить в код заменив `or` на `and` в `buyBias`).
4. **ATR-адаптивный SL.** Вместо фиксированных пунктов — 1.2 × ATR(14).
   Работает и на форексе, и на индексах без перенастройки.
5. **TP2 подтянут к противоположной границе VA.** На Failed Auction это
   даёт естественную цель (VAL → VAH = «полное возвращение в зону стоимости»).
6. **Равномерное распределение объёма бара по бинам** при построении
   профиля — на часовке это даёт более честный POC, чем считать объём
   только по закрытию бара.
7. **Dashboard.** Панель сверху-справа: HTF тренд, MTF bias, VAH/POC/VAL,
   статус Kill Zone — всё в одном взгляде.
8. **Алерты** на BUY / SELL / BOS / CHoCH — можно подключить к webhook-боту.

## 6. Бэктест на данных репозитория

В репозитории лежит почасовка DAX (`DEU.IDX-EUR`) и S&P 500 (`USA500.IDX-USD`)
с 2024-01 по 2026-03. Для бэктеста перенесите Pine-код в **Strategy** —
замените шапку на:

```pinescript
strategy("SMC+VP Sniper Strategy", overlay=true,
     initial_capital=1000, default_qty_type=strategy.percent_of_equity,
     default_qty_value=2, commission_type=strategy.commission.percent,
     commission_value=0.02)
```

И добавьте в конец:

```pinescript
if buySignal
    strategy.entry("L", strategy.long)
    strategy.exit("L-exit", "L", stop=slPx, limit=tp2Px)
if sellSignal
    strategy.entry("S", strategy.short)
    strategy.exit("S-exit", "S", stop=slPx, limit=tp2Px)
```

Запустите **Strategy Tester** → Deep Backtesting → 2 года.
Целевые метрики: Profit Factor > 1.6, Max Drawdown < 15 %.

## 7. Предупреждение

«Разогнать малый депозит в короткие сроки» = высокий риск полного слива.
Даже лучший индикатор не гарантирует прибыль без дисциплины, журнала
сделок и контроля эмоций. Сначала **200+ сделок на демо**, потом реал
с минимальным риском.
